# Промпт-формула для бизнес-задач (маркетинг/анализ)

Источник: разобранный гайд «11 промптов для Claude» с сайта aibasis.ru (Дмитрий Ледовских) — сама формула стандартная (общепринятая практика промпт-инжиниринга), адаптирована сюда как рабочий шаблон для АвтоЭксперт/Motus.

## Формула

Роль + Контекст + Задача + Формат. Убрать любой элемент — ответ хуже.

- **Роль** — кем должен думать Claude («Ты — бизнес-аналитик с опытом в...»)
- **Контекст** — ниша, продукт, конкуренты, аудитория, цена — конкретно, не абстрактно
- **Задача** — пронумерованный список шагов, что сделать
- **Формат** — как оформить ответ (таблица/пункты/структура)

## Шаблоны (адаптировать под АвтоЭксперт / Motus, подставляя реальные данные)

**Анализ конкурентов**
```
Ты — бизнес-аналитик с опытом анализа рынков и конкурентной разведки.
Моя ниша: {напр. импорт авто из Японии на Кипр}
Мои конкуренты: {3–5 названий}
Моя аудитория: {кто покупает}

1. Сравни офферы конкурентов: что обещают, какие боли закрывают
2. Найди их слабые места
3. Определи 2–3 незанятые ниши
4. Как мне отстроиться

Формат: таблица сравнения + топ-3 пробела + рекомендация в 2–3 предложениях
```

**Портрет целевой аудитории**
```
Ты — маркетолог-аналитик с 15-летним опытом исследования ЦА.
Мой продукт: {описание}
Цена: {цена}
Кто уже покупает: {типичный клиент}

Создай 3 детальных сегмента ЦА, для каждого: аватар, 5 болей, 5 желаний,
3 триггера покупки, 3 возражения, 5 цитат живым языком, где обитает, как привлечь.
```

**Поиск слабых мест в продукте/оффере**
```
Ты — продуктовый критик. Говори честно.
Мой продукт: {описание}, цена {цена}, текущий оффер: {текст}, аудитория: {кто}

1. Слабые места в продукте
2. Слабые места в позиционировании
3. Что клиент думает перед тем как уйти без покупки
4. Что конкурент делает лучше
5. Три конкретных изменения для конверсии

Без общих фраз — только конкретика.
```

**Анализ отзывов / CustDev**
```
Ты — аналитик клиентского опыта.
Вот отзывы/интервью: {вставить текст}

1. Топ-5 болей с цитатами
2. Топ-5 похвал с цитатами
3. Скрытые ожидания (не написали прямо, но хотели)
4. Красные флаги, которые отпугивают новых клиентов
5. Фразы, которые можно использовать дословно в рекламе
6. Три конкретных улучшения
```

**Полный аудит бизнеса (раз в квартал)**
```
Ты — опытный бизнес-консультант, разбираешься в маркетинге/продажах/продуктовой стратегии. Прямо, без воды.

Продукт: {что и как}. Аудитория: {кто, боль}. Цена: {цена}.
Выручка/мес: {примерно}. Каналы: {откуда клиенты}. Проблема: {что не работает}. Конкуренты: {2–3}.

1. Диагноз — что реально мешает росту (причины, не симптомы)
2. Анализ позиционирования
3. Слабое звено в воронке
4. Три быстрых победы (2 недели)
5. Стратегический приоритет на 90 дней
6. Вопрос, который я себе не задаю

Если что-то системно не так — скажи прямо.
```

## Частые ошибки (из того же источника, применимо всегда)

- Нет контекста → Claude угадывает. Добавить 3-4 предложения о бизнесе.
- Не указан формат → стена текста. Явно попросить таблицу/пункты.
- Нет роли → ответ уровня ассистента, не эксперта.
- Один запрос без доработки → первый ответ черновик, просить углубить конкретный пункт.
