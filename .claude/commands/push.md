Пользователь запросил быстрый пуш командой `/push` (короткие триггеры-синонимы в чате: "запушь", "запуш", "push"). Это explicit permission для commit+push в рамках этого вызова — не нужно отдельно спрашивать "закоммитить?", но diff обязательно показать перед коммитом (Tier 2, AGENTS.md).

Выполни по порядку:

1. `git status` и `git diff` (staged + unstaged) — покажи короткую сводку изменённых файлов.
2. Если аргумент `$ARGUMENTS` не пустой — используй его как сообщение коммита. Если пустой — сгенерируй короткое сообщение в формате `[Type]: описание` по правилам из AGENTS.md, исходя из реального diff (не выдумывай).
3. `git add` только изменённых/новых файлов, которые относятся к сессии (не `-A` вслепую — проверь, что в статусе нет чужого мусора).
4. `git commit`.
5. `git push origin main` и `git push gdrive main`.
6. Кратко отчитайся: что закоммичено, что запушено, куда. Если push в один из remote упал — сообщи и не пытайся молча чинить (force push и т.п.) без разрешения.

Не трогай CLAUDE.md/AGENTS.md в рамках этой команды, даже если они изменены — эти файлы вне правил автопуша, спроси отдельно.
