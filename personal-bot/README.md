# Personal Bot

Личный Telegram-бот. Сейчас на первом этапе: принимает голосовое сообщение,
распознаёт речь (через OpenAI Whisper) и отвечает текстом, что услышал.
Дальше добавим: понимание смысла (Claude) → создание событий в календаре,
запись мыслей в память, разбор почты.

## Как это устроено (коротко)

- `main.py` — запускает бота, слушает сообщения
- `handlers/voice.py` — что происходит, когда приходит голосовое
- `adapters/` — отдельные "переходники" к внешним сервисам (Whisper, Claude).
  Если захотим заменить сервис — меняется только один файл в этой папке,
  остальной код не трогаем.
- `config.py` — читает ключи из `.env`

## Запуск (первый раз)

1. Установи Python 3.11+ (если ещё нет)
2. В папке `personal-bot` создай виртуальное окружение и поставь зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Скопируй `.env.example` в `.env` и впиши туда свои ключи:
   - `TELEGRAM_BOT_TOKEN` — от @BotFather
   - `OPENAI_API_KEY` — с platform.openai.com
   - `ANTHROPIC_API_KEY` — твой ключ Claude
   - `ALLOWED_CHAT_ID` — твой личный chat_id (узнать через @userinfobot в Telegram)
4. Запусти:
   ```
   python main.py
   ```
5. Напиши боту в Telegram голосовое сообщение — он должен ответить, что расслышал.

## Что уже готово

- Понимание смысла сообщения (событие / перенос / отмена / мысль / почта / поиск запчасти)
- Создание, перенос, отмена событий в Google Calendar
- Запись мыслей в память Claude (синхронизированную папку на Google Drive)
- Алерты о почте по всем 4 ящикам (`config.MAILBOXES`): срочная — каждые 30
  мин, 07:30–22:30, Claude сам решает по каждому письму, срочное оно или нет
  (банки, оплаты, авиабилеты, дедлайны), с учётом накопленных правил из
  прошлых оценок пользователя; дежурная сводка — раз в день, 08:00, все
  непрочитанные письма без фильтра. Каждый срочный алерт приходит с кнопками
  ✅/❌ — оценка пользователя запоминается и влияет на будущие письма от того
  же отправителя/с похожей темой (живая донастройка, без ручных фильтров).
  См. `handlers/mail_alerts.py`, `adapters/urgency_classifier.py`,
  `adapters/urgency_rules.py`.
- Поиск по почте по запросу («найди письмо от Игоря про доступ») — ищет по
  всем 4 ящикам за последние 3 дня, обычный синтаксис Gmail-поиска. См.
  `handlers/mail_search.py`, `adapters/gmail_client.search_mail`.
- Все письма (алерты и поиск) приходят переведёнными на русский — тема
  кликабельная ссылка сразу на письмо в правильном Gmail-аккаунте. Имена
  собственные (бренды, компании) не переводятся. См.
  `adapters/mail_translator.py`, `adapters/gmail_client._gmail_url`.

## Готово (2026-09-02)

- Постоянный хостинг 24/7 — бот работает на Oracle VPS через systemd,
  переживает перезагрузки и падения, автостарт при загрузке сервера.
  OAuth-приложение опубликовано (In production), Calendar-токен больше не
  протухает раз в 7 дней.
- Проверка трат на Oracle Cloud за месяц (не путать с личным/бизнес-учётом
  финансов ниже — это только сам сервер, чтобы не выйти за Always Free).
  Триггер: "баланс", "сколько потратил на oracle". См. `handlers/balance.py`.

## Готово (2026-09-03)

- Бот переехал из личного чата в группу-форум "Personal Bot" (Telegram
  Forum Topics) — 5 тем: Почта, Задачи, AutoExpert, Motus, Финансы.
  `config.py` хранит id тем (`TOPIC_MAIL` и т.д.), `ALLOWED_CHAT_ID` теперь
  id этой группы. Ответы на входящие сообщения (`update.message.reply_text`)
  автоматически уходят в ту же тему, откуда пришло сообщение — менять для
  этого ничего не пришлось. Фоновые алерты (`context.bot.send_message`,
  не ответ на сообщение) явно указывают `message_thread_id` — сейчас все
  почтовые алерты уходят в тему "Почта" (`TOPIC_MAIL`).

## Готово (2026-09-04)

- Маршрутизация ответов бота по темам ПО СМЫСЛУ сообщения, не по тому, куда
  пользователь написал исходный текст — `handlers/dispatch.py._topic_for`.
- Система "закрыто/не закрыто" для мыслей/задач (тема "Задачи"):
  каждая мысль получает id, кнопки "№N" под списком, подтверждение перед
  закрытием ("✅ Да, закрыть / ↩️ Отмена" — защита от случайных нажатий),
  команды "покажи незакрытые"/"покажи выполненные". См.
  `adapters/memory_client.py`, `handlers/dispatch.py`.
- Учёт личных/бизнес-финансов по чекам (AutoExpert/Motus/личное — НЕ Oracle
  Cloud, см. выше): скриншот чека/подписки в тему "Финансы" → Claude Vision
  распознаёт сервис/сумму/категорию (`adapters/receipt_vision.py`) →
  сохраняется (`adapters/expense_store.py`) → карточка с кнопками
  Личное/AutoExpert/Motus, чтобы поправить категорию, если Vision ошибся
  (правки запоминаются в `adapters/expense_rules.py`, тот же паттерн, что
  правила срочности почты). Команда "покажи траты"/"сколько потратил" —
  список + сумма по категории и валюте. См. `handlers/photo.py`,
  `handlers/expenses.py`. Напоминания о регулярных подписках — следующий шаг,
  ещё не сделаны (is_subscription уже определяется и сохраняется).
