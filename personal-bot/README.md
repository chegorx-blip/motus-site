# Personal Bot

Личный Telegram-бот. Сейчас на первом этапе: принимает голосовое сообщение,
распознаёт речь (через OpenAI Whisper) и отвечает текстом, что услышал.
Дальше добавим: понимание смысла (Claude) → создание событий в календаре,
запись мыслей в память, разбор почты.

## Как это устроено (коротко)

- `main.py` — запускает бота, слушает сообщения
- `handlers/voice.py` — что происходит, когда приходит голосовое
- `adapters/` — отдельные "переходники" к внешним сервисам (Whisper, Claude).
  Если захотим заменить сервис — меняется только один файл в этой папке,
  остальной код не трогаем.
- `config.py` — читает ключи из `.env`

## Запуск (первый раз)

1. Установи Python 3.11+ (если ещё нет)
2. В папке `personal-bot` создай виртуальное окружение и поставь зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Скопируй `.env.example` в `.env` и впиши туда свои ключи:
   - `TELEGRAM_BOT_TOKEN` — от @BotFather
   - `OPENAI_API_KEY` — с platform.openai.com
   - `ANTHROPIC_API_KEY` — твой ключ Claude
   - `ALLOWED_CHAT_ID` — твой личный chat_id (узнать через @userinfobot в Telegram)
4. Запусти:
   ```
   python main.py
   ```
5. Напиши боту в Telegram голосовое сообщение — он должен ответить, что расслышал.
